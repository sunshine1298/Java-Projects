# Rock Paper Scissors

A console-based **Rock Paper Scissors** game developed in Java, featuring randomized computer moves and rule-based winner determination.

## Features

* Interactive player input
* Randomized computer selection
* Automatic win, loss, and draw detection
* Input validation

## Tech Stack

**Java** · `Scanner` · `Random`

## How to Run

```bash
javac RockPaperScissors.java
java RockPaperScissors
```

## Gameplay

The player selects **Rock**, **Paper**, or **Scissors**. The computer generates a random choice, and the program determines the outcome based on the standard game rules.
